# Autoresponder

Autoresponder is a Minecraft mod that can automatically reply when a certain chat message is triggered.

## Features

- Detects set chat triggers
- Sends a reply automatically
- Built for Fabric
- Java-based mod project

## Requirements

- Minecraft
- Fabric Loader
- Java 21
- Fabric API

## Install

1. Download the mod file.
2. Put it in your Minecraft mods folder.
3. Start Minecraft with Fabric installed.

## Build from source

Open a terminal in the project folder and run:

```bash
./gradlew build
```
